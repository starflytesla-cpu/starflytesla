# 04 · 執行方案 v1

## 0. 已確定的決策（2026-09）

| # | 問題 | 決定 | 對方案的影響 |
| --- | --- | --- | --- |
| 1 | 目標平台 | **海外社媒**（TikTok、Instagram Reels、YouTube Shorts、Facebook Reels） | VPS 放海外（已購洛杉磯直連中國線路）、不需 ICP 備案；發佈先接 Upload-Post |
| 2 | 商業模式 | **先自營服務自己的客戶**，流程跑通後再整套打包銷售，或改成積分儲值 | MVP 單租戶即可，但資料表先留 `tenant_id`；**從第一天就記錄每個動作的成本**，之後積分定價有依據 |
| 3 | AI 服務商 | **豆包、DeepSeek**；海外用 **kie.ai、OpenRouter** | 做統一的 AI provider 層（都是 OpenAI 相容介面），可以按任務切換廠商 |
| 4 | 審核 | **初期保留人工確認** | 成片與 AI 評論回覆都要經過「待審」佇列，人工點通過才發出 |
| 5 | 起步規模 | **先做一個帳號群** | 1 個帳號群 = 1 份帳號檔案（品牌人設）+ 數個海外社媒帳號；VPS 用入門規格即可 |

### 預設假設（如有不同請告訴我）

- 成片語言預設為**英文**，每個帳號檔案可以設定目標語言；後台介面用中文。
- 工廠人員拍攝時可以講中文，系統會轉寫、翻譯成目標語言的字幕和配音。
- 一個帳號群大約有 3～5 個帳號，每個帳號每天發 1～3 支，總量約每天 10～15 支成片。

## 1. AI 服務分工

| 任務 | 首選 | 備選 | 說明 |
| --- | --- | --- | --- |
| 文案改寫、翻譯、評論分類與回覆建議 | DeepSeek（V4 Flash） | 豆包 Seed（BytePlus ModelArk）/ OpenRouter | 便宜，量大的文字任務都放這裡 |
| 素材畫面理解（看關鍵幀打標籤） | 豆包 Seed Vision（BytePlus ModelArk 國際版） | OpenRouter 上的 Qwen-VL / Gemini | 需要看圖的任務 |
| 語音轉文字 | 本機 faster-whisper | OpenRouter / kie.ai 的語音模型 | 在 VPS 上本機執行，零 API 成本 |
| 配音 TTS | kie.ai（ElevenLabs 多語系） | Edge-TTS（免費，作為 fallback） | 海外受眾對配音品質敏感，正式成片用 ElevenLabs |
| 向量嵌入 | OpenRouter 嵌入模型 | 本機小模型 | 素材檢索和去重用 |
| （之後）AI 生成補充畫面 | kie.ai（Seedance / Veo / Kling） | — | 素材不足時補空鏡頭，不在 MVP 範圍 |

所有 AI 呼叫都經過 `ai_provider` 模組：一個地方設定 key、模型、重試、逾時，並把用量和成本寫入 `usage_ledger`。

## 2. 分階段計畫

總計約 **8～9 週**做出可以給帳號群實際運作的版本。

開發方式：Claude 在雲端環境寫程式、測試並推送到 GitHub；每完成一個可部署的進度，使用者在伺服器執行 `bash infra/scripts/deploy.sh` 更新（見 05-server-setup.md）。

- [x] 專案骨架、調研、架構文件
- [x] 購買 VPS、初始化（Docker、資料碟、防火牆）、壓測通過

- [x] 前端 PWA（手機優先）：登入、儀表板、模型渠道、用量、帳號管理，後續功能預留頁

### Phase 1：拍攝上傳與素材庫（第 2～3 週）✅ 程式完成（2026-10-01）

- [x] 手機拍攝或選檔，tus 斷點續傳（tus-js-client + FastAPI 內建 tus 端點，不另外架 tusd），支援多檔同時傳
- [x] `worker` 服務：檔案指紋 → ffprobe → 720p 預覽檔 → 封面 → FFmpeg 場景偵測切鏡頭 → 關鍵畫面
- [x] 看圖模型（豆包 Seed）逐鏡頭打標籤（場景、主體、標籤、描述、畫面品質），依時長取主要場景自動分類
- [x] 重複偵測：完全相同的檔案（SHA-256）自動略過；畫面幾乎相同的鏡頭（dHash）標示「疑似重複」
- [x] 素材庫：依分類 / 狀態 / 類型 / 關鍵字篩選、預覽、點鏡頭跳轉、人工修正標籤、停用素材或鏡頭、重新分析
- [ ] faster-whisper 轉寫口播（移到 Phase 3，與字幕一起做）
- [ ] 嵌入向量語意搜尋（移到 Phase 3，與自動挑素材一起做）

實作說明：場景偵測先用 FFmpeg 內建的 `scene` 分數（不裝 PySceneDetect / OpenCV，映像檔較小）；重複鏡頭用關鍵畫面的 dHash 漢明距離 ≤ 6 判斷。

**驗收**：在工廠現場用手機上傳 10 支影片，5 分鐘內在素材庫看到切好、標好的片段。

### Phase 2：帳號檔案、模板、文案（第 4 週）✅ 程式完成（2026-10-01）

- [x] 帳號檔案：品牌、行業、受眾、賣點、產品詳情、口吻、**目標語言**（15 種）、行動呼籲、常用 hashtag、禁用詞、綁定音色與語速
- [x] 內建 14 個海外適用的模板（人設型 / 流量型 / 成交型），內建模板唯讀，可「複製為自訂模板」後增刪鏡頭
- [x] DeepSeek 依人設為每個鏡頭寫配音稿與畫面字幕，一次產生 1～5 個彼此不同的版本（背景任務，會參考既有開場避免重複），可人工修改、核准、單版重新產生；出現禁用詞會提醒
- [x] 音色管理：67 個 ElevenLabs 音色（經 kie.ai），預設試聽免費；可用自訂文字試聽、綁定到帳號檔案；文案可「試聽整段配音」
- [x] kie.ai 點數換算成本（`KIE_USD_PER_CREDIT`，預設 US$0.005 / 點，請以帳單為準）

實作說明：模板鏡頭存在 `templates.shots`（JSON），文案建立時複製一份鏡頭到 `scripts.shots`，之後模板修改或刪除都不影響已寫好的文案。Phase 3 混剪只使用「已核准」的文案。

### Phase 3：混剪引擎（第 5～7 週）✅ 程式完成（2026-10-01）

- [x] 時間軸 JSON 規格（`videos.timeline`：每個鏡頭的配音檔、時長、字幕、素材片段與起點）
- [x] 鏡頭 → 素材自動匹配：期望畫面類型 + 標籤關鍵字 + 畫面品質 + 疑似重複扣分 + 近 30 天使用次數扣分 + 隨機數；素材不夠長就接下一段（向量檢索留待素材量大時再加）
- [x] 逐鏡頭 TTS 配音（相同文字 + 音色快取重用，不重複扣點數）→ 以配音長度決定鏡頭時長 → ASS 字幕（上方大字幕 + 下方逐句字幕，依字數分配時間）→ 素材原聲當環境音 → 混音
- [x] FFmpeg 輸出 1080×1920 / 30fps / H.264 成片；字型 Noto（含中日韓、阿拉伯、泰文）
- [x] 矩陣差異化：同一份文案的多支成片用不同隨機種子 → 素材組合、片段起點、放大比例、字幕樣式（4 種）各不相同
- [x] 作品庫：**待審佇列**（預覽 → 通過 / 退回並附原因），單一鏡頭換素材後依時間軸重新渲染（不重新配音），或整支重新挑素材
- [x] 任務中心：所有背景任務的進度、錯誤與手動重試
- [ ] BGM 背景音樂庫（目前用素材原聲當環境音；之後加上音樂上傳）
- [ ] 用真實素材再壓測一次渲染耗時（本機測試：17 秒成片約 20～35 秒渲染）

**驗收**：選一個模板 + 帳號檔案，一鍵產生 5 支彼此不重複的英文成片，人工審核通過率達 60% 以上。

### Phase 4：發佈與評論（第 8～9 週）

- [ ] `PublisherAdapter` 介面 + `UploadPostAdapter`
- [ ] 發佈帳號管理：在 Upload-Post 建立 profile，並把社媒帳號綁到帳號群
- [ ] 發佈任務：審核通過 → 選帳號 → 自動產生各平台標題 / hashtag → 排程 → 失敗重試 → 回寫貼文網址
- [ ] 評論管理：定時拉取評論 → DeepSeek 分類（詢價 / 好評 / 問題 / 垃圾）→ 產生建議回覆 → **人工點選後才送出**
- [ ] 詢價評論醒目提示（這是工廠最在意的轉換）

**驗收**：帳號群所有帳號連續一週每天自動排程發佈，評論都能在後台看到並回覆。

## 3. 試營運期每月成本估算（1 個帳號群，每天約 15 支成片）

| 項目 | 估算（美元 / 月） | 依據 |
| --- | --- | --- |
| VPS（已購：QQG 洛杉磯 6 核 / 12 GB） | 約 6 | 年付 US$70 |
| 自動剪輯（素材切片、轉碼、FFmpeg 渲染成片） | 0（已含在 VPS） | 自研引擎，在自己的 VPS 上執行，FFmpeg 開源免費，不按支或按分鐘收費 |
| Upload-Post | 50（Professional，25 個 profile，含 TikTok） | 免費版和 Basic 版不含 TikTok |
| DeepSeek 文案與評論 | < 10 | V4.1 Flash 每百萬 token：輸入 0.30 / 輸出 1.20 |
| 豆包 Vision 打標籤 | < 10 | Seed 每百萬輸入 token 約 0.25，新帳號另有免費額度 |
| ElevenLabs TTS（kie.ai） | 約 20～100 | 按字元計費，實際以 kie.ai 定價為準；也可以先用免費的 Edge-TTS |
| 物件儲存 | 0～10 | 初期直接用 VPS 本機磁碟 |
| 背景音樂授權 | 0～20 | 免費可商用曲庫（YouTube 音頻庫、Pixabay Music）起步；要更多曲目再訂閱付費曲庫 |
| **合計** | **約 80～210** | 不含開發人力；上線後以 `usage_ledger` 的實際數字為準 |

> 對照：若改用雲端剪輯 API（如 Shotstack 每渲染一分鐘 US$0.20～0.40），每天 15 支 30 秒成片約 225 分鐘 / 月，每月要多付約 US$45～90，而且量越大越貴。自建 FFmpeg 引擎的成本只跟 VPS 規格有關。

## 4. 風險與對策

| 風險 | 對策 |
| --- | --- |
| 矩陣帳號發布太相似的影片，被平台判定為重複 / 非原創，導致限流 | 差異化渲染 + 素材近期使用去重 + 每個帳號使用不同人設、文案和音色；初期發佈頻率保守 |
| AI 配音內容可能需要標示 | 發佈時依平台規定勾選 AI 生成標籤（Upload-Post 參數或平台設定） |
| 依賴 Upload-Post 單一廠商 | 所有發佈都經過 `PublisherAdapter`，之後可以改接官方 API 或其他服務 |
| TikTok 官方 API 需要審核 | 透過 Upload-Post 發佈，不用自己申請審核；日後自建時再申請 |
| AI 服務商不穩或漲價 | `ai_provider` 可隨時切換到 OpenRouter 上的替代模型 |
| 素材不夠，匹配品質差 | 素材庫顯示每個模板缺哪類畫面，提示工廠補拍（「拍攝任務清單」） |
